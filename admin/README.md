# admin

### Compiles and hot-reloads for development
```
turbo dev
```
or from root folder: 

```
turbo admin#dev
```


### Compiles and minifies for production
```
turbo build
```
or from root folder: 

```
turbo admin#build
```

### Lints and fixes files
```
turbo lint
```
or from root folder: 

```
turbo admin#lint
```

### Unit tests
```
turbo test
```
or from root folder: 

```
turbo admin#test
```

### Browser tests (Playwright)
```
bun run test:e2e
```
